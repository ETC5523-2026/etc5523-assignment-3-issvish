
# Vishal | Data in Context

A personal website about data analysis, reproducible research and
communicating complex evidence clearly.

- Author: Vishal Sampath Kumar
- GitHub: https://github.com/issvish
- Website URL: To be added after GitHub Pages publication.

## Intended audience

Australian university students and other non-specialist readers who
remember COVID-19 restrictions and want to understand why vaccination
could reduce, rather than necessarily eliminate, the need for lockdowns
in a 2021 modelling study.

## Featured post

"Vaccines changed the lockdown equation—not an on/off switch" adapts my
Assignment 2 technical report into a public-facing explanation.

The post uses a question-led opening, an original figure, a concise
comparison table, academic citations and a clear historical-context note.
